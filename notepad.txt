================================================================
  HYPERDOPE — NPM PUBLISH GUIDE (Dev Notes)
================================================================

REQUIREMENTS
------------
- Node.js >= 20
- npm account: uziii2208 (https://www.npmjs.com/~uziii2208)
- 2FA enabled on the account (authenticator app or security key)


FIRST-TIME SETUP
----------------
1. Login npm:
   npm login

2. Switch to legacy OTP auth (required for --otp flag to work):
   npm config set auth-type legacy


BEFORE EVERY PUBLISH
--------------------
1. Bump version in package.json:
   - Patch fix  (bug fix)       → 0.1.0 → 0.1.1
   - Minor feature (backwards compat) → 0.1.0 → 0.2.0
   - Breaking change            → 0.1.0 → 1.0.0

2. Verify pack contents (no junk, no photos, no node_modules):
   npm pack --dry-run

   Expected files (~20):
     bin/hyperdope.js
     src/config.js
     src/session.js
     src/server.js
     src/phases/*.js   (6 phase files + index.js)
     src/providers/*.js (4 providers + index.js)
     agent.example.yaml
     README.md
     LICENSE.md
     package.json

   If src/photos/ or other unexpected files appear → check the
   "files" array in package.json and remove the broad "src/" entry.


PUBLISH
-------
Get a fresh OTP code from your authenticator app, then:

   npm publish --access public --otp=<6-digit-code>

OTP expires in 30 seconds — run the command immediately after
copying the code.


TROUBLESHOOTING
---------------
Problem: "bin script was invalid and removed"
Fix:     npm pkg fix
         (normalizes ./bin/hyperdope.js → bin/hyperdope.js)

Problem: "EOTP" with browser URL (not OTP prompt)
Fix:     npm config set auth-type legacy
         Then publish again with --otp flag.

Problem: "You cannot publish over the previously published versions"
Fix:     Bump the version in package.json first.

Problem: src/photos/ or other large files getting bundled
Fix:     In package.json "files", list specific paths instead of
         the broad "src/" directory:
           "src/config.js",
           "src/session.js",
           "src/server.js",
           "src/phases/",
           "src/providers/"


VERIFY PUBLISH SUCCEEDED
------------------------
   npm view hyperdope
   # or open: https://www.npmjs.com/package/hyperdope


QUICK REFERENCE — full publish flow
------------------------------------
   npm pkg fix
   npm pack --dry-run
   npm publish --access public --otp=<code>
